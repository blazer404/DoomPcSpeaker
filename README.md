# DoomPcSpeaker

Консольный плеер, который проигрывает мелодии через **аппаратный PC speaker** — пищалку на материнской плате. Звуковая карта не используется: звук идёт через i8254 и порты `0x43/0x42/0x61` с помощью `inpoutx64.dll`.

Нужен, чтобы послушать мелодии через настоящий бипер, проверить PC speaker и сделать простую звуковую подсказку без звуковой карты. Звук монофонический, прямоугольный; на многих современных пк пищалки нет.

## Что нужно

- Windows x64 и PC speaker на плате;
- .NET 9: SDK для сборки, Runtime для запуска готовой программы;
- `inpoutx64.dll` и папка `melodies\` рядом с `DoomPcSpeaker.exe`;
- запуск от имени администратора: доступ к портам и загрузка драйвера InpOut.

Без доступа к портам программа работает в режиме только для чтения: список и справка доступны, воспроизведение заблокировано.

## Быстрый старт

Запускайте команды из папки с `DoomPcSpeaker.exe`:

```powershell
.\DoomPcSpeaker.exe --list
.\DoomPcSpeaker.exe nokia
.\DoomPcSpeaker.exe tetris,mario,pacman
.\DoomPcSpeaker.exe
```

Последняя команда открывает интерактивный режим.

## Команды запуска

| Команда                                     | Что делает          |
| ------------------------------------------- | ------------------- |
| `DoomPcSpeaker.exe`                         | интерактивный режим |
| `DoomPcSpeaker.exe doom`                    | проиграть трек      |
| `DoomPcSpeaker.exe --play doom` / `-p doom` | то же самое         |
| `DoomPcSpeaker.exe tetris,mario,sonic`      | очередь треков      |
| `DoomPcSpeaker.exe random` / `r`            | случайный трек      |
| `DoomPcSpeaker.exe --list` / `-l`           | список треков       |
| `DoomPcSpeaker.exe --stop` / `-s`           | заглушить спикер    |
| `DoomPcSpeaker.exe --help` / `-h`           | справка             |

Очередь разделяется запятой, точкой с запятой или пробелом. Ключи не зависят от регистра. `--list` и `--help` работают и без доступа к спикеру.

## Интерактивный режим

| Ввод                              | Действие         |
| --------------------------------- | ---------------- |
| `nokia`                           | проиграть трек   |
| `tetris,mario` или `tetris mario` | очередь          |
| `random` / `r`                    | случайный трек   |
| `/list` / `/l`                    | треклист         |
| `/help` / `/h`                    | справка          |
| `/clear` / `/c`                   | очистить экран   |
| `/stop` / `/s`                    | заглушить спикер |
| `/quit` / `/q`                    | выйти            |

Системные команды вводятся только со слешем. Без слеша ввод считается названием трека: `help` не откроет справку, а `/list` покажет треклист. Подсказка команд открывается после `/`, подсказка треков — при вводе ключа без слеша; `Tab` вставляет выбранную подсказку, `↑`/`↓` переключают варианты, `Esc` очищает ввод. `Ctrl+C` во время проигрывания останавливает воспроизведение и оставляет сессию открытой; в простое завершает программу.

## Свои мелодии

Положите `.dpsm` в папку `melodies\` рядом с exe — трек появится в `--list` без пересборки. Вложенные папки не сканируются.

```json
{
  "key": "mytrack",
  "name": "My Track",
  "group": "My songs",
  "notes": [
    [659, 167],
    [587, 167],
    [0, 250]
  ]
}
```

- `key` — ключ для запуска, `name` — название, `group` — группа в списке;
- `notes` — пары `[частота в Гц, длительность в мс]`;
- `0` в частоте — пауза, положительная частота — нота; отрицательная частота и длительность меньше 1 мс считаются ошибкой;
- допустимы алиасы: `alias`/`id`, `title`, `category`, `melody`, а для ноты — `{"freq": 440, "ms": 120}` или `f`, `d`, `duration`.

Битый файл не появится в списке треков, но будет показан в блоке `BROKEN TRACKS` с причиной ошибки.

## Если не работает

| Признак                               | Что сделать                                    |
| ------------------------------------- | ---------------------------------------------- |
| `inpoutx64.dll not found next to exe` | положите DLL рядом с exe                       |
| `wrong architecture (x64 required)`   | используйте x64-версию DLL                     |
| `port access denied`, `INPUT:LOCKED`  | запустите от администратора, проверьте драйвер |
| `no tracks loaded`                    | положите `.dpsm` в `melodies\`                 |
| `not found: 'name'`                   | выполните `--list` и возьмите ключ оттуда      |
| тишина при играющем треке             | проверьте PC speaker в BIOS/UEFI               |

## Сборка и тесты

```powershell
dotnet build .\DoomPcSpeaker.sln -c Debug
dotnet build .\DoomPcSpeaker.sln -c Release
dotnet test .\DoomPcSpeaker.sln -c Debug
dotnet publish .\src\DoomPcSpeaker\DoomPcSpeaker.csproj -c Release -o .\publish
```

Публикация framework-dependent: нужен .NET 9 Runtime. Вместе с exe копируются `inpoutx64.dll` и `melodies\`. Код возврата: `0` — успех, `1` — ошибка.

Версия берётся из `version.txt` в корне репозитория. Измените её перед сборкой или публикацией — номер попадёт в свойства exe и появится в баннере и справке.
